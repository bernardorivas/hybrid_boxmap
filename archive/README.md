# Archive

Material from earlier stages of the project, kept for reference. None of it is
needed to reproduce the paper.

- `demo/`: runners for the earlier examples (thermostat, bipedal walker,
  Garcia passive walker, and others) and for the tagged-chart (Atlas) pipeline.
- `figures/`: their output.
- `data/`: figure manifests of the Atlas pipeline.
- `experiments/`: research scripts from the jump-penalty and boundary-bridging
  investigations.
- `docs/`: notes on the Atlas pipeline and its examples.
- `INSTRUCTIONS.md` and `SUSPENSION_COMPUTATION.md` describe the box-map library
  and the fixed-time Atlas computation.

The scripts here were written to run from the repository root with their
original paths (`demo/...`, `figures/...`). Some default input and output
paths may need to be adjusted.
